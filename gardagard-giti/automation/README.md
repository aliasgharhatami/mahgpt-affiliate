## ساختار

- `automation/sources.json`: فهرست محدود منابع محلی قابل جستجو و محدودیت‌های استفاده
- `automation/discover.py`: کشف تیترها از RSS برای **تحقیق**، بدون کپی مقاله یا تصاویر
- `automation/compose.py`: واکشی متن مقالهٔ اصلی و ساخت پیش‌نویس فارسی؛ نقل‌قول‌های کوتاه داخلی برای راستی‌آزمایی، نه انتشار
- `automation/queue.mjs`: صف مستقل و پنج نوبت روزانه
- `automation/publish.mjs`: ناشر اختصاصی Instagram Login با preflight و idempotency محافظه‌کارانه
- `automation/refresh_ig_token.py`: تمدید اختیاری و امن توکن *معتبر* با PAT دارای Secrets write
- `.github/workflows/giti-daily-discovery.yml`: پایش صبحگاهی و ساخت پیش‌نویس **غیرقابل انتشار**
- `.github/workflows/giti-instagram-slots.yml`: برنامه پنج‌نوبتی با قفل انتشار
- `.github/workflows/giti-token-renewal.yml`: تمدید توکن فقط وقتی اعتبارنامهٔ لازم فراهم باشد
- `.github/workflows/giti-automation-tests.yml`: آزمون‌ها و تست read-only همان حساب Instagram

## سه قفل قبل از انتشار واقعی

۱. `automation/config.json → publication.enabled=true` فقط بعد از کامل‌شدن رندر، انتشار تستی و ارزیابی مجوزها.  
۲. متغیر Repository با نام `GITI_LIVE_PUBLISHING=true`.  
۳. `queue.live=true` و برای **هر پست**، `status=approved`، منبع معتبر، تأیید واقعیات، تأیید حقوق تصویر، URL عمومی JPEG/MP4، مدت ریلز ۳۰–۱۸۰ ثانیه، نریشن زنانه Kore و زیرنویس مطابق صدا.

اگر حتی یکی از این شروط ناقص باشد، انتشار متوقف می‌شود. نه صف MahGPT به این موتور وصل است، نه تصویر روزنامه بدون مجوز خودش منتشر می‌شود.

## تمدید توکن برای جلوگیری از اتصال مکرر

Instagram Login معمولاً توکن long-lived حدود ۶۰روزه می‌دهد. توکن منقضی‌شده قابل احیا نیست، پس ابتدا یک توکن تازه از همان اپ Meta تولید و در `INSTAGRAM_ACCESS_TOKEN` ثبت شود. برای **تمدید خودکار امن**، می‌توان یک PAT ریزدسترسی Github با امکان نوشتن Repository Actions Secrets ساخت و تحت `GITI_GH_SECRETS_PAT` نگهداری کرد. اسکریپت هر ماه دو مرتبه، توکن معتبرِ حداقل ۲۴ ساعت عمرکرده را تمدید و با رمزنگاری libsodium در Secret جایگزین می‌کند. هیچ توکنی در log یا Git ثبت نمی‌شود.

## رسانه‌ها و طراحی

- نسبت: ریلز 9:16 و تصاویر فید 4:5، Stories 9:16.
- سبک: مجله‌ای مدرن کرم/زغالی، عکس اصلی بزرگ، تایپوگرافی فارسی و پرچم کوچک کشور.
- کادر زیرنویس روی عکس باید حدود **۳۰٪ شفاف‌تر از نسخهٔ اولیه** باشد (opacity حدود ۰٫۷۰).
- حذف قطعی: `LOCAL / 01`، `TURKIYE` تزئینیِ اضافی، `EP 001`.
- لوگوی واقعی گرد گیتی فقط به شکل محدود و ظریف در پایین یا گوشه استفاده شود.
- نریشن کاملاً محاوره‌ای ایرانی و یکنواخت، صدای زنانهٔ Kore، متن روی تصویر دقیقاً مطابق جملات گوینده؛ ۳۰–۱۸۰ ثانیه.
- اگر عکس واقعی رخداد وجود ندارد، عکس آرشیویِ مجاز با برچسب «تصویر آرشیوی» یا بازسازی با برچسب «بازسازی تصویری»؛ از جا زدن آن به عنوان فیلم واقعی خودداری شود.

## هزینه و ظرفیت

در حال حاضر هیچ سرویس پولی فعال نشده است. Gemini Free quota و سهمیهٔ GitHub Actions **محدود** هستند. تولید ۳ ریلز روزانه با رندر 1080p، بدون بررسی مصرف دقیقه‌ها و سهمیه‌ها تضمین رایگان و دائمی ندارد. اگر سهمیه تمام شود محتوا منتشر نمی‌شود؛ هزینه‌ای خودکار نباید فعال شود.

**تعهد فعلی:** مرحلهٔ زمان‌بندی، کشف، پیش‌نویس و انتشارِ مشروط آماده است، اما **اتوماسیون انتشار کامل هنوز فعال نیست**. راه‌اندازی نهایی پس از بازیابی دسترسی Instagram و تکمیل رندر/میزبانی/حقوق تصاویر است.

## ادامهٔ پژوهش رایگان رسانه — ۲۶ اکتبر ۲۰۲۶
- برای گسترده‌ترکردن دامنه کشورها، خوراک محلی نپال (Kathmandu Post) اضافه شد؛ صحت آن در اجرای روز بعد باید سنجیده شود.
- موتور پژوهش رسانهٔ تصویری Wikimedia Commons افزوده شد (`automation/commons_media.py`) که مجوزهای CC0/Public Domain/CC-BY را با متادیتای سازنده و مجوز استخراج می‌کند؛ این مرحله **فقط تصویر پیشنهادی** است، خودکار برای انتشار تأیید نمی‌کند.
- استفاده از Pixabay هم مشروط به شرایط مجوز و محدودیت API است؛ چون کاربر هزینه صفر می‌خواهد و تصویر ساختگی نباید به جای عکس واقعی حادثه معرفی شود، انتشار فقط با مجوز و برچسب منبع معتبر انجام می‌شود.
- پایان‌به‌پایان رندر خودکار ۳ MP4 با نریشن و ۲ JPEG هنوز فعال نیست؛ تأیید کیفیت، کلید Pixabay احتمالی یا تصاویر Commons و میزبانی HTTPS باید تکمیل شوند.
