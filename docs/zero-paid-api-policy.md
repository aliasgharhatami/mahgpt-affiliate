# Strict zero-paid-API policy\n\nThis implementation requires **$0 recurring cost**, **no paid API**, and **no new secret**.\n\nThe default translation provider is repository-local static mode. Partner pages are generated from the existing English partner inventory using deterministic templates, locale configuration, and repository-stored labels. The generator does not call the network.\n\nFuture news localization is optional. The English refresh remains authoritative and continues independently. In static mode, no translated news page is emitted unless a human supplies a repository-stored translation. This prevents a missing or unavailable translation from failing the English refresh.\n\nA future provider can implement the `translateNewsItem(item, locale, options)` contract and be explicitly enabled later, without changing routes, templates, hreflang, canonical URLs, affiliate redirects, or sitemap architecture. Enabling it is outside this PR and must never be assumed.\n
